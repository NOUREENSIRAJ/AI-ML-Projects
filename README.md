## Sentiment Analysis Web App
A three-class sentiment classifier — Positive / Neutral / Negative — trained with scikit-learn and served through an interactive Streamlit interface that returns a label and a confidence score for any sentence you type.
# Built with 
Tool Used for Python Core language pandas Loading and filtering the dataset scikit-learn TF-IDF vectorizer, logistic regression, evaluation metrics joblib Saving and loading the trained model Streamlit The web interface.
